# compressorPDF
 Converte html para pdf e comprime o arquivo
 - recebe uma url e valida ela
 - define o nome do arquivo resultante
 - faz o download do arquivo bruto
 - comprime o arquivo utilizando GhostScript

## requisitos do sistema
O sistema utiliza das seguintes bibliotecas:
- requests
- subprocess
- validators
*Requer instalação do GhostScript no ambiente virtual*

## como usar o compressorPDF
1. Rode o arquivo "compressor.py" via terminal
```bash
python ./compressor.py
```
2. Digite a url da página html
3. Digite o nome desejado para o arquivo
4. Os arquivos vão estar disponibilizados na pasta raiz do programa
